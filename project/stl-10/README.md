# STL-10
The STL-10 dataset is an image recognition dataset for developing unsupervised feature learning, deep learning, self-taught learning algorithms. 

The dataset is ~ 2.5GB, and I don't want to duplicate putting it under github again, adding additional network load! All `.bin` files are ignored from being committed, also the sizes are large enough that github does not allow uploads above 100MB.

### Download the [binary files](http://ai.stanford.edu/~acoates/stl10/stl10_binary.tar.gz) from original source
